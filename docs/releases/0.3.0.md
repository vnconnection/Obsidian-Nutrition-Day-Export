# Release 0.3.0

Date: 2026-09-04
Impact: minor
Rationale: Добавлена обратно совместимая опция экспорта питания на 100 г; существующий режим Per consumed остаётся режимом по умолчанию.

## Summary

Nutrition Day Export теперь поддерживает выбор базы расчёта экспорта.

## User-visible changes

- Добавлен выбор `Per consumed` или `Per 100g` в модалке экспорта.
- В режиме `Per 100g` значения КБЖУ берутся на 100 г, а фактически съеденное количество сохраняется в конце строки.
- Для linked food поддержаны `g`, `ml` и `pc`; для inline `pc` возвращается структурированная ошибка.
